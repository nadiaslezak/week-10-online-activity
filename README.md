## Overview

GEOINT Australia is a fictional Earth observation start-up that provides geospatial intelligence (GEOINT). This website is my submission for the Week 10 online activity, where I chose Option 1.

## How to view the website

### Prerequisites

- [Node.js](https://nodejs.org/) (includes npm). Check that it is installed by running `npm -v` in a terminal.

### Steps

1. **Get the code.** Either clone the repository:

```bash
   git clone [repository URL]
```

or download it from GitHub by selecting **Code > Download ZIP**, then unzip the folder.

2. **Open a terminal** in the project folder:

```bash
   cd [project folder name]
```

3. **Install dependencies:**

```bash
   npm install
```

4. **Start the website:**

```bash
   npm run dev
```

5. **View it in your browser.** The terminal will display a local link (usually `http://localhost:5173`). Hold Ctrl (or Cmd on Mac) and click the link, or paste it into your browser.

To stop the website, press `Ctrl + C` in the terminal.
